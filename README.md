# PetroServices - Darío Alexander Herrera
PetroServices es una aplicación web desarrollada con **Angular** para la gestión de un catálogo de productos y equipos utilizados en el sector petrolero.

El proyecto permite consultar, registrar, editar y eliminar productos mediante operaciones CRUD, utilizando **JSON Server** como API REST local para almacenar la información.

También incorpora un sistema de inicio de sesión con dos roles:
- **Administrador:** puede consultar, agregar, editar y eliminar productos.
- **Usuario estándar:** puede visualizar el catálogo de productos.

## Usuarios de prueba
- **Administrador:** admin / admin123
- **Usuario estándar:** operador / operador123

## Estado del proyecto
Se implementaron las operaciones CRUD, el inicio de sesión local y el control de acceso por roles. La integración con Firebase Firestore queda pendiente de desarrollo.
